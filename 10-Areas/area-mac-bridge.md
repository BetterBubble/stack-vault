# Мост мак→сервер: файлы мака для агентов на сервере

**Зачем.** Постановка Президента 06.09 (п.5 ночной карточки): скриншот перетаскивается в окно
серверной сессии прямо из превью-угла — в промпт попадает мак-путь (`/var/folders/…/Screenshot….png`),
файла на сервере нет. Плюс агентам на сервере бывают нужны файлы мака из мест без автокопии.

**Почему pull с мака, а не туннель сервер→мак.** Не требует Remote Login, ключей сервер→мак и дырок
в NAT: направление мак→сервер уже настроено ключом. Цена — задержка до ~3 с. (Remote Login как
запасной канал не понадобился.)

## Устройство (проверено живым прогоном 06.09, 01:19)

| Компонент | Где | Что делает |
|---|---|---|
| `mac-bridge.sh` | мак, демон (`~/claude-stack/tools/`) | цикл 3 с: забирает заявки `~/mac-requests/*.req` с сервера, шлёт файл scp → `~/mac-inbox/`, пишет `.done`/`.err` |
| `mac-get` | сервер, `~/.local/bin/` | CLI для агентов: `mac-get "<мак-путь>"` → серверный путь в stdout (0), отказ (2), таймаут 20 с (3) |
| `mac-fetch-hook.sh` | сервер, UserPromptSubmit | видит мак-путь файла в промпте → сам заказывает доставку → подсказывает агенту серверный путь |
| `com.stack.mac-bridge.plist` | мак, `~/Library/LaunchAgents/` | автозапуск демона при логине (launchctl трогать нельзя — подхватится со следующего входа; сейчас демон запущен nohup'ом) |

**Белый список моста** (санкционировано только это): `/var/folders/*` (временные скриншоты) ·
Desktop · Downloads · Documents · Pictures · stack-vault · claude-stack · tacticum-vault.
`.ssh`, `.env`, secrets, Keychain — отказ всегда. Журнал: `~/.claude/logs/mac-bridge.log`.

**Юзкейс Президента:** Cmd+Shift+4 → превью в углу → перетащил в окно серверной сессии → хук сам
доставит и скажет агенту серверный путь. Важно: доставка идёт сразу на submit, потому что
превью-файл живёт недолго.

**Проверено:** доставка файла с содержимым (сверено cat), отказ вне белого списка, путь с
экранированным пробелом из `/var/folders/…`. Не проверено: живой драг реального превью (нужен
Президент за маком).
