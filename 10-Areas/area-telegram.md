# Телеграм-система: пульт, «ждёт меня», отчёты, голос

**Постановка** (Президент, ночь 06.09, дословно в [[card-dorabotki-nochi-2026-09-06]]): несколько
каналов/ботов под разное · голосовые команды ГД · чат «ждёт меня» · 3–5 чатов под задачи ·
продумано до мелочей · «завтра дам ключи — чтобы после этого всё работало».

## Решение (по ресерчу [[research-telegram-2026-09-06]])

**Один бот + одна супергруппа с forum topics** — не зоопарк ботов. «Разные каналы для разного»
дают топики со своими режимами уведомлений; мульти-бот умножает токены, слушателей и грабли
взаимных триггеров (команда в группе триггерит ВСЕХ ботов), ничего не добавляя. Паттерны переняты
у живых проектов: топик=tmux-окно (alexei-led/ccgram) · inline-апрувы через pending/response-файлы
(jsayubi/ccgram, отложено в «дальше») · verbosity и sandбокс (RichardAtCT).

| Топик | Поток | Уведомления |
|---|---|---|
| 🔔 Ждёт меня | развилки (дельта waiting-queue) · алерты watchdog · блокеры | громко |
| 🎛 Пульт ГД | текст и ГОЛОС → tmux-окно ГД; эхо распознанного | громко |
| 📊 Отчёты | дайджесты, итоги ночи | мьют |
| 🧩 Задача 1–3 | топик = окно лида (`TG_TASK_ROUTES`) | по вкусу |

## Устройство (всё в `~/claude-stack/tools/tg/`, установлено на сервер 06.09)

- **tg-bridge.py** — демон (systemd user `tg-bridge.service`, enable без старта до токена):
  long-polling; ПЕРВЫЙ чек — user_id == TG_OWNER_ID (чужое молча в игнор); роутинг по
  `message_thread_id`; голос: getFile → ffmpeg → **faster-whisper small int8, модель живёт в
  памяти** (загрузка ~38 с один раз, распознавание ~1 с) → эхо «услышал: …» → tmux send-keys -l;
  хвост апдейтов за время простоя демона пропускается (старые команды опаснее переспроса).
- **tg-send.sh** — единственный путь агентов в TG: `tg-send.sh waiting|pult|reports|taskN
  "текст"` или `--file`. Plain text намеренно (MarkdownV2-эскейпинг — минное поле), нарезка
  по 4000 по границам строк, sleep 1 между чанками (лимит группы 20 msg/мин на ВСЕ топики).
- **tg-setup.py** — после вставки токена: getMe → находит группу → createForumTopic ×6 →
  вписывает id в env. Идемпотентен.
- **Интеграции уже вшиты:** `waiting-queue.sh` шлёт ДЕЛЬТУ новых развилок в «Ждёт меня»
  (отпечаток в `~/.claude/.waiting-queue-sent`); `stack-watchdog.sh` шлёт алерт на ПЕРЕХОДЕ
  норма→критика (не сиреной каждые 5 минут). Оба блока тихо спят, пока нет `~/.config/tg/env`.
- **Секреты:** значения только в `~/.config/tg/env` (600), в git — `tg.env.example` без значений.
