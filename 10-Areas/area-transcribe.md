# Транскрипция созвонов — готова, остался живой тест Президента

**Постановка** (06.09, п.12): «сделать штуку с крутой транскрипцией созвонов, чтобы мне осталось
только потестить».

## Состояние на 06.09 (проверено ночью)

Инфраструктура **готова целиком**, чинить было нечего:
- `--setup` чист: «All dependencies ready» (whisper.cpp с Metal, ffmpeg, Swift-хелпер системного звука);
- модель — **large-v3-turbo** (мультиязычная, 547 МБ, скачана), язык жёстко `-l ru` — русский из
  коробки, `base.en` из старой доки давно не используется (только упоминание в help-тексте);
- запись стартует, файл пишется (проверено запуском: заголовок транскрипта создан).

**Почему «потестить» может только Президент:** запись микрофона и системного звука требует
разрешений Microphone + Screen Recording у ТЕРМИНАЛА, и диалог выдачи прав показывается только
живому пользователю за маком. Мой ночной прогон ровно на этом и повис (процесс ждал права).

## Что сделать Президенту (5 минут)

1. В терминале: `/transcribe-md --duration 1 /tmp/test.md` — сказать пару фраз по-русски.
2. macOS спросит права Microphone (и Screen Recording для системного звука) — разрешить.
3. Посмотреть `/tmp/test.md`: реплики `**[HH:MM:SS] You:**` по-русски.
4. Боевой запуск перед созвоном: `/transcribe-md --duration 60 <файл>.md` (микрофон + звук зума).
   Дальше готовый транскрипт разбирается штатным `/after-call`.
