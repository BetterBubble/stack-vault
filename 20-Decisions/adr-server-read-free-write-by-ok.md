# Чтение серверов свободно, изменение — по устному ОК

**Решение Президента, 2026-07-29.** Дословно: «Лид посылал мне кучу апрувов набивных в Клауд код, на
чтение через SSH чего-то, так не должно быть, должен сам действовать, без апрува, с серверами можно
работать… помимо деплоя в прод, правок на сервере — это только мое ок, один раз и дальше свободно».
И уточнение: «они в теории могут что хотят делать на сервере без апрувов технически, но им явно
прописано в инструкции не делать правок на сервере/пушей без просто в чате моего Ок».

## Что было не так

Охрана прода была размазана по подтверждениям Claude Code: `ssh_execute` стоял в `ask`, поэтому
**каждая** команда — включая `tail` лога — требовала клика. Плюс гейт различал только ИМЯ инструмента,
а не то, что этой командой делают: `ssh_execute` целиком считался прод-действием и требовал открытого
окна автономии. Итог: чтобы посмотреть лог, нужно было либо кликнуть апрув, либо открыть окно прода —
то есть охрана мешала ровно там, где ничего не защищала, и приучала кликать не глядя.

## Что решено

| | Раньше | Теперь |
|---|---|---|
| Чтение сервера (логи, статусы, SELECT) | апрув на каждую команду + окно | свободно, без апрува и без окна |
| Изменение на сервере, деплой | окно, которое открывает только человек руками | ОК в чате один раз на задачу → окно открывает агент с основанием |
| Мерж в `main` | человек | человек (не изменилось) |
| Кнопки стопа `AUTONOMY_OFF` / `AGENTS_OFF` | только человек | только человек (не изменилось) |

## Как это сделано механически

- **`settings.json`:** `ssh_execute` и `ssh_db_query` переехали из `ask` в `allow`. `ssh_db_dump`
  остался в `ask` — он пишет файл на сервер, то есть изменением является.
- **`guard.sh`:** появился разбор полезной нагрузки — `ssh_payload_readonly()`. Читающее проходит без
  окна, меняющее упирается. Перечень читающего узкий: 40 программ плюс таблицы допустимых подкоманд
  (`systemctl status`, `docker logs`, `git log`, `journalctl` без `--vacuum`). Всё незнакомое считается
  записью.
- **Закреплено 73 тестами** в `stack-doctor.sh` на обе стороны. Два прежних теста переписаны: они
  ожидали `deny` на `ssh_execute {"command":"ls"}` и после верной правки защищали бы уже отменённое
  правило.

## Круг слома по этому классификатору (2026-07-30, 99 форм)

Первая версия классификатора прожила час и была сломана семь раз — подробности и таблица находок в
[[tech-debt]]. Что изменилось по существу после починки:

- **разбиение на сегменты идёт по токенам лексера, а не по сырой строке.** Одной правкой закрылись и
  дыра (одиночный `&` не был разделителем), и ложный отказ (`|` внутри кавычек рвал команду пополам);
- **у многоцелевых программ разбираются глобальные флаги по арности** — иначе значение флага встаёт
  на место подкоманды: `docker --log-level info stop api` читался как чтение `info`;
- **проверяются позиционные аргументы, а не только флаги** — `uniq вход выход` перезаписывает файл
  без единого редиректа;
- **`ssh_download` убран из перечня read-only** и разбирается по нагрузке: он не меняет сервер, но
  перезаписывает локальный файл, и этим подменялся сам гейт;
- **имена интерпретаторов проверяются по голове сегмента**, а не поиском по всей строке — иначе
  `cat /etc/ssh/sshd_config` отказывал из-за слова `ssh` в пути.

## Чем платим (называется прямо)

**Это тот же догоняющий разбор текста, что и в правиле A2.** Классификация по строке команды знает
только те формы, которые кто-то успел придумать. Отличие одно, и оно принципиальное: **направление
отказа обратное**. В A2 незнакомая форма проходит (и это дыра), здесь незнакомая форма считается
записью (и это лишний вопрос). Цена ошибки — один апрув вместо необратимой команды на проде.

**Окно перестало быть барьером.** Раньше оно означало «человек своими руками разрешил»; теперь —
«агент объявил под запись, что разрешение было». Проверить, что ОК действительно прозвучал в чате,
механически невозможно, и притворяться, что окно это барьер, было бы ложью о механизме. Что осталось
настоящим: журнал (`~/.claude/autonomy.log` пишет `by=`, `role=`, `session=`, `ok=`), таймер (окно
истекает само) и обе ручные кнопки стопа, которых агент не касается.

Норму «без ОК прод не трогаем» держит текст персон — [[adr-window-opened-by-agent]].
