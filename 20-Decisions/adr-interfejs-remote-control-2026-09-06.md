# ADR: интерфейс — Remote Control; iTerm2 перестаёт быть рабочим местом

**Решение** (принято мной в рамках мандата Президента 06.09: «Как выберешь, узнаешь, делай полную
миграцию» + «все решения принимай сам»): интерфейсом компании агентов становится **официальный
Remote Control** Claude Code — сессии живут в tmux на сервере как жили, а Президент видит их
списком и пишет им через **claude.ai/code** (браузер) и **приложение Claude** (iPhone/Mac).
Терминал остаётся тонкой служебной форточкой.

## Что это решает из его жалоб (п.1 ночной карточки)

- **«iTerm лагает»** — iTerm перестаёт быть рабочим местом вовсе; смотреть на агентов теперь в
  вебе/приложении, красиво из коробки, официально.
- **«Обрывается SSH — приходится перезапускать отображение»** — транспорт RC это HTTPS с очередями
  и авто-реконнектом от самого CLI; обрыв SSH с мака вообще ничего не рвёт. Раскладка окон iTerm
  и osascript-скрипт теряют критичность (можно не чинить и не переносить).
- Бонусы: пуши на телефон о решениях · картинки в сессию с телефона/браузера (смежно с п.5) ·
  видны сабагенты · модель/effort с устройства.

## Что сделано 06.09 (проверено вживую)

1. Пилот: `claude --remote-control` в tmux сервера → «/remote-control is active», URL выдан. ✅
2. `remoteControlAtStartup: true` в серверный settings.json (+ machine-оверлей для доктора) —
   **каждая** будущая сессия сервера регистрируется сама, без флага. Проверено второй сессией. ✅
3. Имена в списке — уже человеческие: обвязка запускает роли с `--name "$role"` (roles.zsh:143). ✅
4. env сервера чист (нет ANTHROPIC_BASE_URL/DISABLE_TELEMETRY), логин Claude Max живой. ✅

## Осознанные компромиссы и границы

- **Транскрипты RC-сессий хранятся на серверах Anthropic** (для синка устройств). Исполнение,
  файлы, хуки — на нашей машине. Принято для личного стека; неприемлемо станет → план Б: Happy
  self-hosted (E2E), план В: Ghostty+mosh (терминальный путь, ресерч сохранён).
- **На маке RC пока НЕ включён**: взаимодействие RC с permission-промптами наших гейтов не гонялось
  живьём. Первым обкатываем сервер (там боль обрывов), мак — после обкатки.
- tmux на сервере остаётся супервизором процессов — это рекомендация самих доков RC; обвязка,
  хуки и роли не тронуты.
- Ghostty НЕ ставился: миграция на RC делает замену терминала косметикой. Если терминал-форточка
  начнёт раздражать — ресерч терминалов готов ([[research-terminal-2026-09-06]], топ: Ghostty+mosh).

## Что осталось (утро)

- Президенту: открыть **claude.ai/code** (или вкладку Code в приложении Claude) — после подъёма
  компании там будет список всех сессий по именам ролей; включить в `/config` пуши
  «when actions required».
- Обкатать неделю; затем решить: включать ли RC на локальных сессиях мака.
