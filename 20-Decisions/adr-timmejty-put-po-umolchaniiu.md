# Тиммейты — путь по умолчанию для параллельной работы лида

## Решение
Лид распараллеливает работу тиммейтами внутри своей сессии ПО УМОЛЧАНИЮ, без команды и напоминания.
Критерий: два и более независимых куска → тиммейты; один тяжёлый одноразовый кусок → субагент.

## Контекст
Механизм был разрешён, но описан как опция («если возьмёшься — скажи»). Президент 26.07: «должно
само сразу работать, а не мне говорить, напоминать лиду, что он тиммейт и лид».

## Альтернативы
- Оставить опцией. Отвергнуто: опция, требующая напоминания, на практике не используется — ровно
  так же не запускались две роли, не открытые ни разу за месяц.
- Заменить субагентов тиммейтами полностью. Отвергнуто: для одноразового куска тиммейт дороже без
  выгоды, общий почтовый ящик там не нужен.

## Почему так
Тиммейты дают общий список задач и переписку между собой — это нужно, когда куски пересекаются.
Субагент возвращает результат и умирает, чего достаточно для «прочитай и отдай числа».

## Риск, названный прямо
Механизм экспериментальный и ни разу не запускался. Поэтому в персону вписан явный откат: не
поднялись — одна строка в отчёт, переход на субагентов, работа продолжается. Без этого первое же
падение стало бы остановкой.
