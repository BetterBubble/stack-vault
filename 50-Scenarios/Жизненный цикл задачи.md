# Жизненный цикл задачи — состояния и переходы

**Добавлено сверх исходного списка.** Не было названо прямо, но без него артефакты не
сшиваются: [[Список задач на день]], [[Статус дня]], [[Статус задачи]] и
[[Закрытые задачи — ждут PR и деплоя]] говорят об одной и той же задаче — и должны называть её
состояние **одинаково**. Часть [[Сценарий работы стека]].

## Состояния

| Состояние | Что значит | Где видно |
|---|---|---|
| **поставлена** | задача есть, лид не назначен | [[Список задач на день]] |
| **план пишется** | лид пишет план реализации | [[Статус дня]] |
| **ждёт апрува** | план у меня | [[Свод планов на апрув]] |
| **на переделку** | я вернул с комментарием, идёт второй цикл | [[Свод планов на апрув]] |
| **в работе** | план апрувнут, лид делает | [[Статус задачи]] |
| **стоит** | работа встала: блокер на мне или внешнее ожидание | [[Решения ждущие меня]] |
| **на проверке** | лид сделал, ГД сверяет с первоначальным планом | [[Статус дня]] |
| **закрыта** | сделано, проверено, гейты пройдены → **пуш мне** | [[Закрытые задачи — ждут PR и деплоя]] |
| **смержена** | PR влит мной | [[Закрытые задачи — ждут PR и деплоя]] |
| **задеплоена** | выкачено мной, задача завершена | [[Отчёт дня]] |
| **в долге** | отложена осознанно, с датой и причиной | [[Список задач с долгом]] |
| **снята** | решено не делать; причина записана | [[Список задач с долгом]] |

## Правила переходов

- **«Закрыта» не значит «готово для людей».** Между «закрыта» и «задеплоена» стоят мои руки, и
  это единственный участок, где работа ждёт человека по замыслу, а не по дефекту.
- **«Стоит» обязано иметь адресата.** Либо пункт в [[Решения ждущие меня]], либо внешнее
  событие с датой. «Стоит просто так» — это поломка, а не состояние.
- **Пока задача стоит, лид берёт следующий шаг плана** или следующую задачу. Простой одной
  задачи не должен останавливать день.
- **Из «в работе» нельзя прыгнуть в «закрыта» минуя «на проверке»** — иначе «сделали» ничем не
  проверяется.
- **«Снята» — полноценный исход.** Задача, которую решили не делать, записывается с причиной, а
  не удаляется молча: через месяц она вернётся как «а почему мы это не сделали».

## Что у задачи есть всегда

- **Имя** — одинаковое во всех артефактах, по нему я её узнаю.
- **Лид** — один. Двое на одной задаче правят общее и теряют правки друг друга.
- **Направление** — для группировки в отчётах.
- **Дата создания** — по ней видно возраст, особенно в долге.
- **Ссылки:** план реализации ↔ статус задачи ↔ источники.

**Не разобрано:** нужен ли задаче короткий идентификатор (номер) вдобавок к имени — с ним удобнее
ссылаться и искать, без него меньше бюрократии; связь с трекером (Taiga) — задача заводится там
же или только в заметках.
