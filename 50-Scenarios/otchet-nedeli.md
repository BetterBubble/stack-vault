# Отчёт недели

Артефакт №5. Часть [[scenario-raboty-steka]].

**Что это.** Место, где **просто хранятся отчёты дня** ([[otchet-dnya]]) полные версии, за неделю, и, сверху общая сводка. Отдельной работы по сбору не предполагается: это контейнер, а не новый документ.

**Зачем.** Ответ на вопрос «что сделано за неделю» без перечитывания семи заметок.

**Сводка:** Собирается сверху кракто 2 абзацами и пересобирается каждый раз после нового отчета дня. Период недели по дням отчета сверху в сводке жирно
