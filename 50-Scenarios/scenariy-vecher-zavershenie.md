# Сценарий: завершение работы (вечер)

Сценарий №9. Часть [[scenario-raboty-steka]].

**В течение дня, по мере закрытия.** Задача закрыта полностью → **Президенту приходит пуш** →
задача встаёт в **список закрытых, ждущих PR и/или деплоя**. Разбор, PR, мерж и деплой Президент
делает **сам, по мере закрытия задач**, — это под его апрувом и не делегируется.

**Вечер, когда всё закрыто, разобрано и задеплоено — собирается на утро:**

1. [[spisok-zadach-na-den]] на завтра.
2. [[plan-realizacii-zadachi]] по этим задачам.
3. [[otchet-dnya]] — краткая и полная версия в одной заметке, со ссылками на детальные заметки
   по задачам.

**Ночная работа.** Если есть работа, которую можно поставить на ночь, Президент её ставит; по
исходу делается отдельная заметка, а сделанное помечается в утреннем плане как «сделано за
ночь» — **но из плана не уходит**.

**Не разобрано:** сам список закрытых, ждущих PR и деплоя, — отдельный артефакт или срез
[[spisok-zadach-na-den]]; что происходит с задачей, которую вечером не успели разобрать.
