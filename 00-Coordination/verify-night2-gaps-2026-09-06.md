# Ночь-2: что подведёт Президента утром (проверено фактами, ничего не правлено)

Мандат: НЕДОСТАЮЩЕЕ, рамка «обещания карточки [[card-dorabotki-nochi-2026-09-06]] против фактов».
Ранжировано по боли утром. Второй критик ищет сломанное — здесь только дыры.

## 1. КРИТИЧНО — сервер отстал от мака на 2 коммита, и именно на телеграм-двусторонность

- **Обещано:** пульт ГД двусторонний — «ответ возвращается в телеграм» (HANDBOOK:57, коммит
  d680bde «tg-пульт двусторонний: префикс [tg:топик] + правило персонам»).
- **Чего нет:** на сервере HEAD = `6a77201`, мак = `cca0bfc`. В серверном
  `~/claude-stack/tools/tg/tg-bridge.py` (6468 байт, 03:01) `grep -c "tg:"` = **0** — префикса
  нет вовсе; серверные `roles/director.md` и `roles/lead.md` без правила «дублируй ответ через
  tg-send». А мост и роли работают ИМЕННО на сервере: утром Президент по README запустит
  `tg-bridge`, скажет голосом команду — она дойдёт до окна ГД, а **ответ останется в терминале**.
  Тот самый разрыв, ради которого делался d680bde, на сервере не закрыт.
- **Чем доказано:** `ssh stack 'git -C ~/claude-stack log -1'` → 6a77201; `ssh stack 'grep -c
  "tg:" ~/claude-stack/tools/tg/tg-bridge.py'` → 0; мак `git rev-parse HEAD` → cca0bfc
  (= origin/main на GitHub, live ls-remote).
- **README-tg.md не содержит шага «синхронизируй сервер»** — по написанному утро запускает
  устаревший мост.
- **Предложение:** до утра доставить git на сервер (штатный канал бандлов) — это изменение
  сервера, решает лид/ГД, не воркер; либо строкой 0 в README: `git -C ~/claude-stack pull`
  + `systemctl --user restart tg-bridge` после правки env.

## 2. stack-state.md не знает ночи-2 — catchup утром соврёт

- **Обещано:** «stack-state переписан» (карточка, 04:30) и «утром можно всё нормально разобрать».
- **Чего нет:** [[stack-state]] (updated 04:30) покрывает только ночь-1. В «Следующий шаг» НЕТ
  двух главных утренних пунктов — телеграма (п.0) и мержа PR автономки (п.0а); нет ни слова про
  tg-систему, живой прогон автономки, TeammateIdle, дрифт-чек. `/catchup` и `/status` читают
  state — уведут в сторону от карточки.
- **Чем доказано:** grep 'телеграм|автономк|PR' по stack-state → 0 совпадений по ночи-2.
- **Предложение:** дописать блок «ночь-2» и оба пункта в «Следующий шаг».

## 3. Итог ночи не закоммичен и не запушен — с телефона его не видно

- **Обещано/ожидаемо:** «генерируй сразу артефакты в память, чтобы утром всё разобрать»;
  линия «мобильность» — vault на GitHub и есть мобильный доступ к памяти.
- **Чего нет:** в `~/stack-vault` — 4 незапушенных коммита + **6 новых файлов ночи untracked**
  (report-night, area-telegram, research-telegram, plan/impl/verify-tools-readme) и 3 modified
  (карточка, tech-debt, _workers). Авто-коммит срабатывает лишь при закрытии сессии.
- **Чем доказано:** `git status --short` и `git log origin/main..HEAD` в stack-vault.
- **Предложение:** закоммитить и запушить vault до конца ночи (личный контур — пуш свободен).

## 4. Возврат ответа в TG держится на вере, не на механизме

- **Ожидаемо:** вся ночь заменяла дисциплину механикой (grant-write, watchdog, гейты). Здесь —
  нет: контракт «[tg:топик] → роль обязана вызвать tg-send» живёт только текстом в персонах
  (director.md:416, lead.md:429). Роль забудет / скомпактится — Президент с телефона слеп, и
  никакой хук этого не поймает.
- **Чем доказано:** grep tg-send по хукам — только waiting-queue.sh; Stop-хуков про [tg:] нет.
- **Предложение:** механическая страховка — Stop-hook: в транскрипте хода есть входящее
  `[tg:X]`, а вызова tg-send не было → напоминание роли (по образцу pr-reminder).

## 5. Топик «📊 Отчёты» построен, но писать в него некому

- **Обещано:** пуш-поводы «свод готов · итог ночи» (README-tg, правила канала).
- **Чего нет:** продюсеры не подключены: `tg-send` не вызывается ни из `working-end`, ни из
  autonomous-feature (report-night), ни из иных команд — grep по commands/skills/workflows → 0.
  Реально подключены только waiting-queue («Ждёт меня») и watchdog (алерты). «Итог ночи» в TG
  слать некому даже после вставки токена.
- **Предложение:** шаг в working-end и в финал автономки: `tg-send reports "<свод>"` с тихим
  пропуском, если env отсутствует (паттерн waiting-queue уже такой).

## 6. Отклонения от дословной постановки не названы Президенту явно

- «**Боты несколько**» → сделан один (аргументы в [[area-telegram]] — мульти-бот умножает токены
  и взаимные триггеры). Решение зрелое, НО в утреннем списке карточки (п.0) отклонение не
  названо ни строкой — Президент увидит одного бота и должен сам догадаться, что это решение,
  а не недоделка. Предложение: одна строка в п.0: «просил несколько ботов — сделан один с
  топиками, почему: area-telegram».
- «**3–5 чатов под задачи**» → топики «Задача 1–3» создаются, но `TG_TASK_ROUTES` пуст: вход в
  них мёртв до ручной привязки (README честно относит в «после обкатки»). По постановке «завтра
  дам ключи — чтобы после этого всё работало» — работает частично. Пометить в п.0 списком
  «работает сразу / после привязки».
