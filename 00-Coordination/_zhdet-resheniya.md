# Что ждёт решения Президента

**Файл собирается механически** скриптом `~/.claude/hooks/waiting-queue.sh` из доски.
Править его руками бессмысленно — перезапишется. Пункт уходит отсюда, когда исчезает
из источника, то есть когда лид его закрыл. Источник указан у каждой строки.

Чтобы развилка сюда попала, лид ставит в своей карточке строку:

```
@ЖДЁТ: одна фраза — что решить · [[карточка]]
```
