# Где стоим по работе над стеком

**Переписывается целиком и компактно (≤1 экран).** Хроника — [[stack-chronology-2026-10]].
Долг — [[tech-debt]]. Решения — `20-Decisions/`.

## Где стоим (2026-10-01)

Рабочий контур перенесён с Claude на Codex. Mac — интерфейс, основная компания ролей работает на
сервере `stack`. Старые процессы Claude остановлены; их сессии сохранены только как история.

- На Mac и сервере одинаковые 10 custom agents, модели `gpt-6.1-sol/high`, MCP и общая память
  ролей (304 файла). Telegram, голос и мосты в миграцию не включались.
- Новые серверные чаты открыты в Codex: ГД, `AI PaaS`, `AI PaaS Platform`, `AI PaaS Delivery`.
  Они унаследовали историю старых сессий и подняли рабочий контекст/документы.
- Guard работает только для top-level чатов, открытых после установки hooks. Живой smoke нового
  чата подтвердил регистрацию critic и блокировку `touch`/`apply_patch`. Старые импортированные
  чаты нельзя использовать как исполнителей.
- Read-only роли пропускают только доказуемое чтение; implementer запускает любой shell только как
  `codex sandbox -P :workspace -C <worktree> -- ...`. Синтетический и sandbox-smoke подтвердили:
  запись вне worktree блокируется, внутри worktree проходит.
- `stack-vault` сведён и чист на одном `main` на Mac, сервере и GitHub. Рабочий `tacticum-vault`
  объединён на Mac и передан напрямую в серверный `main`; GitHub пока не обновлялся из-за старого
  blob `Маркетинговые_материалы_new.tar` размером 713 МБ в серверной истории.

## Следующий шаг

- Довести серверный `tacticum-vault`: сохранить последние записи новых лидов, переключить рабочее
  дерево с `feat` на объединённый `main`, затем вернуть локальный Basic Memory из паузы.
- Провести живой implementer-smoke из linked worktree уже через новую серверную сессию.
- После рабочего минимума: вынести HTTP MCP bearer из `config.toml` в хранилище секретов;
  разобрать 713-МБ blob без переписывания опубликованной истории; освободить место на `go-dev-3`.

## Что отсеяно — не делать сейчас

Telegram, голос, внешние мосты, тесты обходных флагов и чистка `go-dev-3` не входят в первый
приоритет миграции. Кнопки `AUTONOMY_OFF`, `AGENTS_OFF`, `NUDGE_OFF` не трогать.
