  Пользователь `alex` с sudo без пароля, вход только по ключу, root по паролю закрыт, ufw,
  fail2ban, автообновления, zsh + roles.zsh, tmux, Node 22, uv.
- **Claude Code 2.1.233 и три MCP** (basic-memory, serena, context7) — подключены и отвечают.
- **WireGuard** — сервер + конфиги мака и телефона, весь трафик в туннель, DNS внутри.
- **Syncthing** — двусторонний синк `stack-vault` и `tacticum-vault`, проверен в обе стороны
  и на удаление. `.git` из синка исключён намеренно: git и Syncthing портят репозиторий, а не
  конфликтуют по файлу.
- **Граница прав изменена** — [[adr-stek-hodit-na-svoyu-mashinu]]. Запрет «стек не ходит на
  серверы» сужен до «не ходит на **чужие**»: своя машина в `~/.claude/stack-hosts`, остальное
  закрыто целиком. Проверено 11 пробами, три обходные формы (цепочка, ProxyCommand, `-F`) закрыты.
- **Четыре врущих проверки починены.** Два `open-lead` гонялись на живом реестре и падали от
  открытого окна · проверка мониторов сыпала markdown вместо имён и **скрывала настоящий дубль**
  (сирота от 11.08 вычерпывала сигналы, убита) · шаблон новой машины разошёлся с живым конфигом.
- **`open-lead` научился tmux** — без этого компания ролей на сервере не поднималась вовсе:
  скрипт умел только вкладку iTerm2. Проверено вживую, окно создаётся.
- **Захардкоженный `/Users/bubblemac` в тесте ночного пайплайна** — заменён на путь от `__dirname`.
  155 ok на обеих машинах.
