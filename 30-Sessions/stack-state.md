# Где стоим по работе над стеком

Хроника — [[stack-chronology-2026-07]]. Долг — [[tech-debt]]. Решения — `20-Decisions/` (23 ADR).

## Где стоим (2026-08-16, 12:55)

**Сервер арендован и поднят.** Доктор на маке — **554 ok, 0 провалов, 2 варна** (лучший результат
с 09.08; было 549/4/3). На сервере — 549 ok, 7 провалов, 12 варнов, и провалы там **чужие**:
это дефекты рабочего vault, невидимые из контура стека, потому что в нём `AGENT_VAULT` указывает
на `stack-vault`. Разбирает их рабочая роль, не стек.

  конфликтуют по файлу.

  скрипт умел только вкладку iTerm2. Проверено вживую, окно создаётся.

  **Каталогов на маке 69, репозиториев 9** — остальные 40 worktree, их перенос бессмыслен.

## Следующий шаг

1. **3x-ui + Reality на своём домене** — решение Президента 16.08, ждёт **покупки домена**.
   Текущий VLESS работает и остаётся до замены. Оговорка к постановке: Reality своего домена
   не требует по устройству (он заимствует чужое рукопожатие); «свой домен» — это либо
   VLESS+TLS с сертификатом, либо Reality с маскировкой под собственный сайт. Развилку
   разобрать при возврате к задаче.
2. **Секреты под Linux** — Keychain там нет, `secret.sh` не работает. Без этого не поедет
   `ssh-manager` и доступы к инфраструктуре заказчика. Решение не выбрано.
3. **Телеграм-транспорт** — ждёт токена бота от @BotFather.
4. **Восемь пайплайнов дня** выведены из сырья интервью 13.08 и предложены Президенту;
   ждут его правки и выбора, с какого начинать.
5. **Доктор на сервере** даёт 7 провалов по рабочему vault (досье фич без `type`, статусы вне
   словаря, `session-state` 128 КБ). Это **не дефекты переноса**: в контуре стека `AGENT_VAULT`
   указывает на `stack-vault`, поэтому слой не проверялся вовсе. Разбирает рабочая роль.

## Что заблокировано

**Токен телеграм-бота** и **покупка домена** — действия Президента.
**Секреты под Linux** — решение не принято. **Песочница Bash** — ждёт обновления CLI.
**`iva-mcp`** — одобрение ждёт выпуска ключа.

## Проверка при холодном старте

```bash
bash ~/.claude/hooks/stack-doctor.sh                    # мак: 554 ok, 0 провалов
ssh alex@159.195.46.213 'bash ~/.claude/hooks/stack-doctor.sh'   # сервер

```

**Урок захода.** Три из четырёх провалов доктора оказались дефектами самих проверок, а не того,
что они проверяют: тест падал от открытого окна, отчёт сыпал разметкой вместо имён. Пока проверка
врёт, настоящий дефект под ней не виден — дубль монитора висел с 11.08 и обнаружился ровно в тот
час, когда отчёт научился печатать имена.
